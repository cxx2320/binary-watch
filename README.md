# KINETIC 01 — 二进制腕表网页

一个以参考图 `OIP-C.webp` 为灵感的单页二进制腕表体验。使用原生 HTML、CSS 和 JavaScript 构建，无构建步骤、无外部依赖。

## 打开方式

直接双击 `index.html`，或将它拖入浏览器窗口即可。页面会读取设备本地时间并实时刷新。

## 读时规则

- 上方 **4 位**是小时：权重 `8 · 4 · 2 · 1`
- 下方 **6 位**是分钟：权重 `32 · 16 · 8 · 4 · 2 · 1`
- 蓝色光点 = `1`，暗色光点 = `0`
- 将所有亮起位置的权重相加，即为当前读数

例如 `1 0 0 1` = 9，`1 0 1 0 0 1` = 41，读作 **09:41**。

## 交互

- 点击右侧面板的 **24 小时制** 开关，或点击表冠，可在 12 / 24 小时制之间切换
- 鼠标在腕表区域移动时，表壳会产生轻微 3D 倾斜与高光变化
- 面板实时显示当前小时、分钟、秒、日期、时区和二进制算式
- 12 小时制下会显示 AM / PM，并写入 `localStorage` 保留偏好
- 支持手机、平板和桌面布局，并适配 `prefers-reduced-motion`

## 文件结构

```
index.html   页面结构
styles.css   腕表、表盘、布局、动效与响应式样式
script.js    二进制时间渲染、12/24 小时切换、3D 倾斜
preview.png  桌面端预览截图
OIP-C.webp   原始参考图
```

## 设计说明

表盘采用拉丝银色金属、同心装饰环、电路蚀刻与冷光蓝 LED 光点；表壳、表冠和金属表带均由 CSS 绘制，因此所有视觉元素都能自由缩放且无需额外图片资源。
