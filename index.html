HOW TO READ / 02

两行光，
一整天。

这只表只做一件事：把时间翻译成二进制。上方四位代表小时，下方六位代表分钟，所有阅读规则都可以在十秒内学会。

READOUT / EXAMPLE 09:41
HOURS 8 + 1 = 9
MINUTES 32 + 8 + 1 = 41
H8  4  2  1 M32  16  8  4  2  1
01

从右向左，权重翻倍

每一枚光点都有一个固定权重。最右侧是 1，向左依次是 2、4、8……分钟行的最左位是 32。记住这个顺序，就读懂了一半。

02

亮起为 1，熄灭为 0

蓝光点代表 1，暗色点代表 0。把所有亮起位置的权重相加，得到的数字就是这一行要表达的值。

03

上读小时，下读分钟

四枚光点组成小时，六枚光点组成分钟。例如上方 1 0 0 1 是 9，下方 1 0 1 0 0 1 是 41，此刻就是 09:41。

±

每一秒，重新编码

页面按本地时区实时刷新。右侧解码面板会同步显示当前二进制值，让眼睛逐步适应这种新的读时方式。

SYSTEM / 03

少一点指针，
多一点光。

4+6

十枚光点

四位小时与六位分钟，刚好覆盖完整的 24 小时。没有多余信息，也没有一秒被遗漏。

12/24

双制式

24 小时制保持表盘纯粹；12 小时制则以 AM / PM 标记，适配不同的读时习惯。

1s

实时同步

时间直接读取设备本地时钟，每一次刷新都发生在正确的一秒，无需手动校准。
